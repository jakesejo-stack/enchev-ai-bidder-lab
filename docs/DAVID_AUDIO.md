# DAVID — собствени аудио записи

DAVID е гласът на търга: съобщава нови оферти, удължаване, оставащо време и края. AiBidder (балончето) дава съветите. Това са две отделни неща.

## Как DAVID избира глас

1. **Твой запис** за това събитие, ако е вписан в `public/audio/david/manifest.json`.
2. Ако няма запис: **български синтезиран глас** на устройството.
3. Ако няма и такъв: **само надписи**.

Надписите винаги се показват. Сумите (например „43 500 €“) винаги са в надписа. Записите са кратки фиксирани фрази, без числа.

## Как да добавиш записи

1. Сложи файловете в `public/audio/david/`. Подходящи формати: MP3, M4A/AAC или OGG; моно, 1–3 секунди.
2. Впиши ги в `public/audio/david/manifest.json`:

```json
{
  "version": 1,
  "clips": {
    "new_bid": "new_bid.mp3",
    "outbid": "outbid.mp3",
    "time_10": "time_10.mp3"
  }
}
```

3. Commit → Vercel Preview. Не е нужна промяна в кода. Събитията без запис продължават със синтезирания глас или с надписи.

Само файлове от същия сайт работят (CSP `media-src 'self'`). Външни линкове се пропускат.

## Ключове и какво да казва записът

| Ключ | Фраза |
|---|---|
| `connected` | Свързан съм с търга. |
| `new_bid` | Има нова оферта. |
| `outbid` | Някой те надмина. |
| `you_lead` | Твоята оферта е най-високата. |
| `extended` | Търгът е удължен. |
| `time_60` | Остава една минута. |
| `time_30` | Остават трийсет секунди. |
| `time_10` | Остават десет секунди. |
| `ended` | Търгът приключи. |
| `ended_won` | Търгът приключи. Твоята оферта е най-високата. |
| `connection_lost` | Връзката е прекъсната. Наддаването е спряно. |
| `connection_back` | Връзката е възстановена. |
| `offline` | Устройството е без интернет. |
| `bid_rejected` | Офертата не е приета. |
| `voice_on` | Гласът на DAVID е включен. |
| `confirm_opened` | Отворих потвърждението. Провери сумата и потвърди. |

Списъкът е и в кода: `CLIP_KEYS` в `src/voice/david.ts`.

## Права

Използвай само записи, за които имаш права (твой глас, или глас с писмено съгласие и лиценз). Не качвай чужд или клониран глас без разрешение. Аудиото на Митко остава в неговия проект и не се копира тук без неговото изрично съгласие.
